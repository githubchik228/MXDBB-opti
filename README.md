# MXDBB Opti

Windows gaming-PC optimizer based on the original FPS-TOOL engine.

## Included
- Original reversible Windows optimization engine
- PC scan and hardware summary
- Registry backup and Windows restore point
- Deep cleanup
- Power, Game Mode, Game DVR, GPU, network and responsiveness tweaks
- MXDBB Opti interface and branding
- Reversible HAGS option
- CLI: selftest, dryrun, apply, revert

## Build
Run `src\\build.cmd` on Windows with .NET Framework 4 installed.

The project intentionally has no licensing system or telemetry.
